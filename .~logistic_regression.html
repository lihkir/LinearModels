Regresión Logística#

Modelos con una Variable de Respuesta Binaria#

  • Consideremos un escenario en el cual la variable de respuesta dentro de un problema de regresión toma únicamente dos valores posibles: \(0\) y \(1\). Esta codificación puede ser una asignación arbitraria derivada de una respuesta cualitativa observada.

  • Por ejemplo, la respuesta puede representar el resultado de una prueba funcional eléctrica en un dispositivo semiconductor, donde los resultados posibles son “éxito” (el dispositivo opera correctamente) o “falla” (debido a un cortocircuito, circuito abierto, u otro defecto funcional).

  • Supongamos que el modelo es de la forma:

    ()#\[ y_i = \mathbf{x}_i' \boldsymbol{\beta} + \varepsilon_i \]

    donde \(\mathbf{x}_{i}^{'} = [1, x_{i1}, x_{i2}, \dots, x_{ik}]\), \(\boldsymbol{\beta} = [\beta_0, \beta_1, \dots, \beta_k]\), y la variable de respuesta \(y_i\) solo puede tomar los valores \(0\) o \(1\).

  • Decimos que, \(\mathbf{x}_i'\boldsymbol{\beta}\) es la parte determinista o sistemática del modelo y \(\varepsilon_i\) es la parte aleatoria, representa el error o la variabilidad no explicada por los predictores.

  • Se asume que \(y_i\) es una variable aleatoria Bernoulli, cuya distribución de probabilidad es la siguiente:

\[\begin{split} \begin{align} \mathbb{P}(y_i = 1) &= \pi_i\\ \mathbb{P}(y_i = 0) &= 1 - \pi_i \end{align} \end{split}\]

  • Dado que \(\mathbb{E}(\varepsilon_i) = 0\), el valor esperado de la variable de respuesta es:

\[ \mathbb{E}(y_i) = 1 \cdot \pi_i + 0 \cdot (1 - \pi_i) = \pi_i \]

  • Esto implica:

\[ \mathbb{E}(y_i) = \mathbf{x}_i' \boldsymbol{\beta} = \pi_i \]

  • Es decir, el valor esperado de la variable de respuesta, dado por \(\mathbb{E}(y_i)\), representa directamente la probabilidad de que dicha variable adopte el valor 1.

  • Sin embargo, existen problemas fundamentales con el modelo de regresión en la Ecuación (10.1). En primer lugar, dado que la respuesta es binaria, los términos de error \(\varepsilon_i\) solo pueden tomar dos valores, a saber:

\[\begin{split} \varepsilon_i = \begin{cases} 1 - \mathbf{x}_i' \boldsymbol{\beta}, & \text{si } y_i = 1 \\ - \mathbf{x}_i' \boldsymbol{\beta}, & \text{si } y_i = 0 \end{cases} \end{split}\]

Distribución de Bernoulli

  • Distribución de Bernoulli: Modelo probabilístico que describe experimentos con únicamente dos resultados posibles:

    • Éxito (\(X = 1\)) con probabilidad \(p\)

    • Fracaso (\(X = 0\)) con probabilidad \(1-p\)

  • Función de Densidad de Probabilidad (FDP)

\[\begin{split} \mathbb{P}(X = x) = \begin{cases} p & \text{si } x = 1 \\ 1-p & \text{si } x = 0 \end{cases} \end{split}\]

Alternativamente:

\[ \mathbb{P}(X = x) = p^x (1-p)^{1-x} \quad \text{para } x \in \{0,1\} \]

  • Propiedades Clave

Concepto

Fórmula

Media (\(\mu\))

\(\mathbb{E}[X] = p\)

Varianza (\(\sigma^2\))

\(\mathbb{Var}(X) = \mathbb{P}(1-p)\)

Asimetría

\(\displaystyle{\frac{1-2p}{\sqrt{\mathbb{P}(1-p)}}}\)

Ejemplo: Se lanza un dado una vez. Si sale 3, se gana el juego. Si sale cualquier otro número, se pierde. Sea \(X\) la variable aleatoria que representa el número de veces que sale un 3 (éxito).

  • Paso 1: Definir la Variable Aleatoria Bernoulli

    • Espacio muestral: \(\{1, 2, 3, 4, 5, 6\}\) (resultados posibles del dado).

    • Éxito (\(X = 1\)): Sale un 3.

    • Fracaso (\(X = 0\)): Sale cualquier otro número (1, 2, 4, 5, 6).

  • Paso 2: Calcular Probabilidades

    • Probabilidad de éxito (\(p\)):

      \[ \mathbb{P}(X = 1) = \mathbb{P}(\text{Sacar 3}) = \frac{1}{6} \]

    • Probabilidad de fracaso (\(1 - p\)):

      \[ \mathbb{P}(X = 0) = \mathbb{P}(\text{No sacar 3}) = \frac{5}{6} \]

  • Paso 3: Construir la Distribución de Probabilidad. La distribución de Bernoulli para \(X\) se resume en la siguiente tabla:

\(X\)

\(\mathbb{P}(X)\)

Descripción

1

\(\frac{1}{6}\)

Gana (sale 3)

0

\(\frac{5}{6}\)

Pierde (no sale 3)

  • Paso 4: Verificar Propiedades

    1. No negatividad: \(\mathbb{P}(X) \geq 0\) para todo \(X\).

    2. Suma de probabilidades:
      $\( \mathbb{P}(X=1) + \mathbb{P}(X=0) = \frac{1}{6} + \frac{5}{6} = 1 \)$

  • Paso 5: Calcular Media y Varianza

    • Media (Valor esperado):
      $\( \mu = \mathbb{E}[X] = 1 \cdot \mathbb{P}(X=1) + 0 \cdot \mathbb{P}(X=0) = \frac{1}{6} \)$

    • Varianza:
      $\( \sigma^2 = \mathbb{Var}(X) = \mathbb{P}(1 - p) = \frac{1}{6} \cdot \frac{5}{6} = \frac{5}{36} \)$

  • Interpretación Práctica

    • Solo hay dos resultados posibles (éxito/fracaso).

    • La probabilidad de éxito (\(p\)) es constante.

    • Los eventos son independientes (un lanzamiento no afecta a otro).

  • Aplicación: Este modelo puede extenderse a cualquier juego o experimento con dos resultados discretos y probabilidad fija (ej: cara/cruz, aprobar/reprobar, etc.).

  • La variable \(X\) sigue una distribución Bernoulli con parámetro \(p = \frac{1}{6}\). Su función de masa de probabilidad (PMF) es:

\[\begin{split} \mathbb{P}(X = x) = \begin{cases} \frac{1}{6} & \text{si } x = 1, \\ \frac{5}{6} & \text{si } x = 0. \end{cases} \end{split}\]

Pruebas sobre coeficientes individuales y subconjuntos de coeficientes#

A menudo resulta fundamental evaluar si uno o más coeficientes de regresión múltiple son iguales a cero. Este análisis permite determinar si ciertas variables explicativas contribuyen significativamente al modelo.

Sea el modelo general:

\[ Y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_k x_k + \varepsilon \]

El objetivo es probar si un subconjunto de \(p\) de los \(k\) coeficientes \(\beta_j\) es igual a cero. Formalmente, se plantea la hipótesis nula:

()#\[ H_0: \beta_{j_1} = \beta_{j_2} = \cdots = \beta_{j_p} = 0 \]

Esta prueba se lleva a cabo utilizando un estadístico \(F\), el cual compara dos modelos:

  • Modelo completo: incluye todos los regresores.

  • Modelo reducido: excluye las \(p\) variables bajo prueba.

El estadístico \(F\) se define como:

()#\[ F_0 = \frac{(SSE_R - SSE_F) / p}{SSE_F / (n - k - 1)} \]

donde:

  • \(SSE_R\) es la suma de cuadrados del error del modelo reducido.

  • \(SSE_F\) es la suma de cuadrados del error del modelo completo.

  • \(p\) es el número de restricciones.

  • \(n\) es el número total de observaciones.

  • \(k\) es el número de variables explicativas en el modelo completo.

Este estadístico sigue una distribución \(F\) con \(p\) y \(n - k - 1\) grados de libertad bajo \(H_0\). Si el valor de \(F_0\) excede el valor crítico correspondiente, se rechaza la hipótesis nula.

Pruebas individuales sobre coeficientes#

Para evaluar si un solo coeficiente \(\beta_j\) es igual a cero, se utiliza la estadística \(t\):

()#\[ t_0 = \frac{b_j}{\sqrt{\widehat{\operatorname{Var}}(b_j)}} \]

bajo la hipótesis nula:

()#\[ H_0: \beta_j = 0 \]

Esta estadística se distribuye como una \(t\) de Student con \(n - k - 1\) grados de libertad bajo \(H_0\). El valor \(b_j\) representa el estimador del coeficiente, mientras que \(\widehat{\operatorname{Var}}(b_j)\) es su varianza estimada.

Interpretación con Python#

En Python, este procedimiento se implementa fácilmente utilizando la librería statsmodels. El siguiente fragmento de código ilustra cómo realizar pruebas individuales:

import statsmodels.api as sm

X = sm.add_constant(X)  # Agrega intercepto
modelo = sm.OLS(y, X).fit()
print(modelo.summary())
