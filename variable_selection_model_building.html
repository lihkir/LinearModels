8. Selección de variables y construcción de modelos#

8.1. Introducción#

8.1.1. El Problema de Construcción del Modelo#

En los capítulos anteriores se asumió que las variables regresoras incluidas en el modelo eran importantes y conocidas de antemano. El enfoque estuvo centrado en asegurar que la forma funcional del modelo fuera adecuada y que los supuestos estadísticos fundamentales no fueran violados.

En muchas aplicaciones, los criterios teóricos o la experiencia previa pueden ayudar en la selección de las variables regresoras apropiadas. Hasta ahora, se ha seguido el enfoque clásico para la selección de modelos de regresión, el cual parte de la suposición de que conocemos la forma básica del modelo y las variables que deben considerarse. Esta estrategia clásica se puede resumir de la siguiente forma:

  1. Ajustar el modelo completo, es decir, el que incluye todas las variables regresoras en consideración.

  2. Realizar un análisis exhaustivo del modelo completo, incluyendo un análisis de residuos detallado. Es recomendable también investigar posibles problemas de colinealidad.

  3. Evaluar la necesidad de aplicar transformaciones a la variable respuesta o a algunas de las regresoras.

  4. Utilizar las pruebas t individuales para eliminar regresores innecesarios y editar el modelo.

  5. Evaluar la adecuación del modelo editado, prestando especial atención al análisis de residuos.

En la práctica, especialmente cuando se trabaja con datos históricos, el analista suele disponer de un conjunto amplio de variables regresoras candidatas, de las cuales solo unas pocas resultan relevantes. Este proceso de identificar un subconjunto adecuado de regresores se conoce como el problema de selección de variables.

La selección adecuada de variables es crucial, particularmente cuando existe multicolinealidad. De hecho, el método más común para corregirla consiste en seleccionar variables cuidadosamente. Aunque la selección de variables no elimina por completo la multicolinealidad, puede justificar la presencia de regresores altamente correlacionados en el modelo final cuando estos son necesarios desde un punto de vista explicativo.

La multicolinealidad no es el único motivo para aplicar técnicas de selección de variables. Incluso relaciones moderadas entre regresores, que podrían no ser identificadas como problemáticas mediante diagnósticos estándar, pueden afectar significativamente la calidad del modelo.

La construcción de un modelo de regresión que solo incluya un subconjunto de los regresores disponibles implica un conflicto entre dos objetivos:

  • (1) Incluir la mayor cantidad posible de regresores, de forma que la información contenida en estas variables contribuya a la predicción de \(y\).

  • (2) Incluir la menor cantidad posible de regresores, ya que la varianza de la predicción \(\hat{y}\) aumenta con el número de regresores. Además, modelos más grandes conllevan mayores costos de recolección de datos y mantenimiento.

El proceso de encontrar un modelo que equilibre estos dos objetivos se conoce como la selección de la “mejor” ecuación de regresión. Sin embargo, no existe una definición única de “mejor” modelo. Existen múltiples algoritmos para la selección de variables, y es común que produzcan diferentes subconjuntos de regresores como óptimos.

La selección de variables suele tratarse bajo condiciones idealizadas, asumiendo que la especificación funcional de los regresores es conocida (por ejemplo, \(1/x_1\), \(\ln x_2\)), y que no existen valores atípicos ni observaciones influyentes. Sin embargo, en la práctica estas condiciones rara vez se cumplen.

El análisis de residuos (véase el Capítulo 4) es útil para:

  • Sugerir formas funcionales alternativas para los regresores.

  • Identificar nuevos regresores candidatos.

  • Detectar defectos en los datos, como observaciones atípicas o influyentes.

Por tanto, la evaluación de la adecuación del modelo está estrechamente vinculada al problema de selección de variables. Aunque lo ideal sería abordar ambos aspectos simultáneamente, en la práctica se recurre a un enfoque iterativo:

  1. Aplicar una estrategia de selección de variables.

  2. Evaluar el modelo resultante en términos de especificación funcional, valores atípicos y observaciones influyentes.

Este proceso puede requerir varias iteraciones hasta obtener un modelo adecuado.

Ninguno de los métodos de selección de variables garantiza encontrar la mejor ecuación de regresión para un conjunto de datos dado. De hecho, a menudo no existe una única mejor ecuación, sino varias que son estadísticamente equivalentes. Dado que los algoritmos de selección de variables dependen en gran medida del software utilizado, existe el riesgo de depositar excesiva confianza en los resultados computacionales. Este riesgo debe evitarse.

La experiencia, el criterio profesional en el área de aplicación y los factores subjetivos juegan un papel importante en la selección de variables. Los procedimientos de selección deben utilizarse como herramientas exploratorias para estudiar la estructura del conjunto de datos.

Referencias recomendadas sobre selección de variables en regresión incluyen:

  • Cox y Snell (1974),

  • Hocking (1972, 1976),

  • Hocking y LaMotte (1973),

  • Myers (1990),

  • Thompson (1978a, b).

8.1.2. Consecuencias de una especificación incorrecta del modelo#

Para motivar el uso de técnicas de selección de variables, revisamos brevemente las consecuencias de especificar incorrectamente un modelo. Supongamos que hay \(K\) regresores candidatos \(x_1, x_2, \dots, x_K\) y que se dispone de \(n \geq K + 1\) observaciones sobre estos regresores y la respuesta \(y\).

El modelo completo, que contiene los \(K\) regresores, es:

\[ y_i = \beta_0 + \sum_{j=1}^K \beta_j x_{ij} + \varepsilon_i,\quad i = 1, 2, \dots, n \tag{10.1a}\label{eq:10.1a} \]

o, de forma matricial:

\[ \mathbf{y} = \mathbf{X} \boldsymbol{\beta} + \mathbf{e} \tag{10.1b}\label{eq:10.1b} \]

Asumimos que la lista de regresores candidatos contiene todas las variables importantes. Notamos que el modelo incluye un término de intercepto \(\beta_0\), el cual usualmente se mantiene en el modelo y no se somete a selección.

Si se eliminan \(r\) regresores del modelo completo, entonces el número de regresores retenidos es \(p = K + 1 - r\) (incluyendo el intercepto). Por tanto, el subconjunto de regresores contiene \(p - 1 = K - r\) de los regresores originales.

Reescribimos el modelo completo como:

\[ \mathbf{y} = \mathbf{X}_p \boldsymbol{\beta}_p + \mathbf{X}_r \boldsymbol{\beta}_r + \mathbf{e} \tag{10.2}\label{eq:10.2} \]

donde \(\mathbf{X}_p\) es una matriz \(n \times p\) con el intercepto y las variables retenidas, y \(\mathbf{X}_r\) es una matriz \(n \times r\) con las variables eliminadas. El vector de parámetros \(\boldsymbol{\beta}\) se particiona como \(\boldsymbol{\beta}_p\) y \(\boldsymbol{\beta}_r\).

El estimador de mínimos cuadrados del modelo completo es:

\[ \hat{\boldsymbol{\beta}}^* = (\mathbf{X}^\top \mathbf{X})^{-1} \mathbf{X}^\top \mathbf{y} \tag{10.3}\label{eq:10.3} \]

y la estimación de la varianza del error es:

\[ \hat{\sigma}^{*2} = \frac{\mathbf{y}^\top (\mathbf{I} - \mathbf{X}(\mathbf{X}^\top \mathbf{X})^{-1} \mathbf{X}^\top) \mathbf{y}}{n - K - 1} \tag{10.4}\label{eq:10.4} \]

El modelo de subconjunto se expresa como:

\[ \mathbf{y} = \mathbf{X}_p \boldsymbol{\beta}_p + \mathbf{e} \tag{10.5}\label{eq:10.5} \]

y su estimador de mínimos cuadrados es:

\[ \hat{\boldsymbol{\beta}}_p = (\mathbf{X}_p^\top \mathbf{X}_p)^{-1} \mathbf{X}_p^\top \mathbf{y} \tag{10.6}\label{eq:10.6} \]

La varianza residual estimada para el modelo de subconjunto es:

\[ \hat{\sigma}^2 = \frac{\mathbf{y}^\top (\mathbf{I} - \mathbf{X}_p(\mathbf{X}_p^\top \mathbf{X}_p)^{-1} \mathbf{X}_p^\top) \mathbf{y}}{n - p} \tag{10.7}\label{eq:10.7} \]

Resultados clave sobre los estimadores del modelo reducido:

  1. El valor esperado de \(\hat{\boldsymbol{\beta}}_p\) es:

\[ \mathbb{E}[\hat{\boldsymbol{\beta}}_p] = \boldsymbol{\beta}_p + (\mathbf{X}_p^\top \mathbf{X}_p)^{-1} \mathbf{X}_p^\top \mathbf{X}_r \boldsymbol{\beta}_r = \boldsymbol{\beta}_p + \mathbf{A} \boldsymbol{\beta}_r \]

donde \(\mathbf{A} = (\mathbf{X}_p^\top \mathbf{X}_p)^{-1} \mathbf{X}_p^\top \mathbf{X}_r\) es la matriz de aliasado. El estimador \(\hat{\boldsymbol{\beta}}_p\) es sesgado salvo que \(\boldsymbol{\beta}_r = \mathbf{0}\) o que \(\mathbf{X}_p^\top \mathbf{X}_r = \mathbf{0}\).

  1. Las varianzas de los estimadores son:

\[ \operatorname{Var}(\hat{\boldsymbol{\beta}}_p) = \sigma^2 (\mathbf{X}_p^\top \mathbf{X}_p)^{-1}, \quad \operatorname{Var}(\hat{\boldsymbol{\beta}}^*) = \sigma^2 (\mathbf{X}^\top \mathbf{X})^{-1} \]

Además, se cumple que:

\[ \operatorname{Var}(\hat{\boldsymbol{\beta}}^*_p) - \operatorname{Var}(\hat{\boldsymbol{\beta}}_p) \text{ es semidefinida positiva} \]

por lo que eliminar variables nunca incrementa la varianza de los coeficientes retenidos.

  1. Como \(\hat{\boldsymbol{\beta}}_p\) es sesgado, se recomienda evaluar la precisión en términos del error cuadrático medio (ECM):

\[ \operatorname{MSE}(\hat{\boldsymbol{\theta}}) = \operatorname{Var}(\hat{\boldsymbol{\theta}}) + \left[\mathbb{E}(\hat{\boldsymbol{\theta}}) - \boldsymbol{\theta} \right]^2 \]

El ECM del modelo reducido es:

\[ \operatorname{MSE}(\hat{\boldsymbol{\beta}}_p) = \sigma^2 (\mathbf{X}_p^\top \mathbf{X}_p)^{-1} + \mathbf{A} \boldsymbol{\beta}_r \boldsymbol{\beta}_r^\top \mathbf{A}^\top \]

Si \(\operatorname{Var}(\hat{\boldsymbol{\beta}}_r^*) - \boldsymbol{\beta}_r \boldsymbol{\beta}_r^\top\) es semidefinida positiva, entonces:

\[ \operatorname{Var}(\hat{\boldsymbol{\beta}}^*_p) - \operatorname{MSE}(\hat{\boldsymbol{\beta}}_p) \text{ es semidefinida positiva} \]

por lo tanto, el modelo reducido puede tener menor ECM si los coeficientes eliminados son pequeños.

  1. La estimación \(\hat{\sigma}^{*2}\) es insesgada en el modelo completo. En el modelo reducido, el valor esperado es:

\[ \mathbb{E}(\hat{\sigma}^2) = \sigma^2 + \frac{\boldsymbol{\beta}_r^\top \mathbf{X}_r^\top [\mathbf{I} - \mathbf{X}_p(\mathbf{X}_p^\top \mathbf{X}_p)^{-1} \mathbf{X}_p^\top] \mathbf{X}_r \boldsymbol{\beta}_r}{n - p} \]

lo cual implica que \(\hat{\sigma}^2\) es sesgada hacia arriba.

  1. Para predecir en un nuevo punto \(\mathbf{x}^\top = [\mathbf{x}_p^\top,\ \mathbf{x}_r^\top]\):

  • Modelo completo:

\[ \hat{y}^* = \mathbf{x}^\top \hat{\boldsymbol{\beta}}^*, \quad \operatorname{Var}(\hat{y}^*) = \sigma^2 \left[1 + \mathbf{x}^\top (\mathbf{X}^\top \mathbf{X})^{-1} \mathbf{x} \right] \]

  • Modelo reducido:

\[ \hat{y} = \mathbf{x}_p^\top \hat{\boldsymbol{\beta}}_p, \quad \mathbb{E}(\hat{y}) = \mathbf{x}_p^\top \boldsymbol{\beta}_p + \mathbf{x}_p^\top \mathbf{A} \boldsymbol{\beta}_r \]

y su ECM es:

\[ \operatorname{MSE}(\hat{y}) = \sigma^2 \left[1 + \mathbf{x}_p^\top (\mathbf{X}_p^\top \mathbf{X}_p)^{-1} \mathbf{x}_p \right] + (\mathbf{x}_p^\top \mathbf{A} \boldsymbol{\beta}_r - \mathbf{x}_r^\top \boldsymbol{\beta}_r)^2 \]

Por tanto, \(\hat{y}\) será sesgado a menos que \(\mathbf{x}_p^\top \mathbf{A} \boldsymbol{\beta}_r = \mathbf{x}_r^\top \boldsymbol{\beta}_r\). Además, si se cumple que:

\[ \operatorname{Var}(\hat{y}^*) \geq \operatorname{MSE}(\hat{y}) \]

entonces el modelo reducido puede ofrecer mejor precisión de predicción, incluso con sesgo.

Resumen: La selección de variables puede reducir la varianza de los estimadores y de las predicciones, aunque introduce sesgo si las variables eliminadas no son totalmente irrelevantes. Si el sesgo es pequeño, el ECM puede mejorar en el modelo reducido. Por otro lado, mantener variables irrelevantes aumenta la varianza innecesariamente. Además, los modelos ajustados sobre datos retrospectivos suelen estar afectados por errores, rangos limitados y puntos influyentes, lo cual afecta críticamente la selección de variables. En tales casos, es recomendable recolectar nuevos datos mediante experimentos diseñados.

8.1.3. Criterios para evaluar modelos de regresión con subconjuntos#

Dos aspectos fundamentales del problema de selección de variables son: (1) generar modelos con subconjuntos y (2) decidir cuál de ellos es mejor. En esta sección se discuten criterios para evaluar y comparar modelos de regresión con subconjuntos. En la Sección 10.2 se presentan métodos computacionales para llevar a cabo la selección.

8.1.3.1. Coeficiente de determinación múltiple#

Una medida ampliamente utilizada para evaluar la adecuación de un modelo de regresión es el coeficiente de determinación múltiple \(R^2\). Denotamos por \(R_p^2\) el coeficiente de determinación correspondiente a un modelo de subconjunto con \(p\) términos (es decir, \(p - 1\) regresores más un intercepto \(\beta_0\)). Computacionalmente, se define como:

\[ R_p^2 = \frac{\text{SSR}(p)}{\text{SST}} = 1 - \frac{\text{SSRes}(p)}{\text{SST}} \tag{10.8}\label{eq:10.8} \]

donde \(\text{SSR}(p)\) es la suma de cuadrados de regresión del modelo de \(p\) términos, y \(\text{SSRes}(p)\) es la suma de cuadrados residual correspondiente. Existen \(\binom{K}{p - 1}\) posibles valores de \(R_p^2\) para cada tamaño de subconjunto \(p\).

\(R_p^2\) siempre aumenta al agregar regresores, alcanzando su máximo cuando \(p = K + 1\) (modelo completo). Por ello, el criterio se usa agregando regresores hasta que una nueva variable proporciona solo una pequeña ganancia en \(R_p^2\). Este enfoque se ilustra en la Figura 10.1, donde se grafica el valor máximo de \(R_p^2\) frente a \(p\). Generalmente, el analista selecciona el tamaño del modelo en el punto donde se aprecia una curvatura o “codo” en la gráfica, lo cual requiere juicio experto.

Dado que no existe un valor «óptimo» de \(R^2\) para un modelo reducido, buscamos un valor satisfactorio. Aitkin (1974) propuso un test para identificar subconjuntos que no difieren significativamente del modelo completo en términos de \(R^2\). Definimos:

\[ R_0^2 = 1 - (1 - R_{K+1}^2)(1 + d_{\alpha, n, K}) \tag{10.9}\label{eq:10.9} \]

donde

\[ d_{\alpha, n, K} = \frac{K F_{\alpha, K, n - K - 1}}{n - K - 1} \]

y \(R_{K+1}^2\) es el \(R^2\) del modelo completo. Cualquier subconjunto que produzca un \(R^2 > R_0^2\) se denomina subconjunto \(R^2\)-adecuado al nivel \(\alpha\).

Aunque \(R^2\) no es ideal para elegir el número óptimo de regresores, para un número fijo \(p\), se puede comparar entre modelos con el mismo número de variables. En ese caso, se prefieren los modelos con mayor \(R_p^2\).

8.1.3.2. Coeficiente de determinación ajustado#

Para evitar los inconvenientes de interpretar \(R^2\), algunos analistas prefieren usar el coeficiente de determinación ajustado, definido como:

\[ R^2_{\text{Adj},\ p} = 1 - \left(\frac{n - 1}{n - p}\right)(1 - R_p^2) \tag{10.10}\label{eq:10.10} \]

Este estadístico no necesariamente aumenta al incluir nuevos regresores. De hecho, se ha demostrado (Edwards, 1969; Haitovski, 1969; Seber, 1977) que si se agregan \(s\) regresores al modelo, entonces:

  • \(R^2_{\text{Adj},\ p + s} > R^2_{\text{Adj},\ p}\) si y solo si el estadístico F parcial para probar la significancia de los \(s\) regresores adicionales es mayor que 1.

Por lo tanto, un criterio alternativo para seleccionar el subconjunto óptimo consiste en maximizar \(R^2_{\text{Adj}}\), lo cual equivale al uso del estadístico \(F\) parcial, que se presenta en la siguiente sección.

8.1.4. Criterios adicionales para evaluar modelos con subconjuntos#

8.1.4.1. Cuadrado medio residual#

El cuadrado medio residual para un modelo de regresión con \(p\) términos se define como:

\[ \text{MSRes}(p) = \frac{\text{SSRes}(p)}{n - p} \tag{10.11}\label{eq:10.11} \]

Dado que \(\text{SSRes}(p)\) disminuye al aumentar \(p\), \(\text{MSRes}(p)\) suele disminuir inicialmente, luego se estabiliza, y finalmente puede aumentar. Este incremento ocurre cuando la reducción en \(\text{SSRes}(p)\) no compensa la pérdida de un grado de libertad en el denominador. Es decir, añadir un regresor ocasiona que:

\[ \text{MSRes}(p+1) > \text{MSRes}(p) \]

si la disminución en la suma de cuadrados residuales es menor que \(\text{MSRes}(p)\). Los analistas que emplean este criterio suelen graficar \(\text{MSRes}(p)\) vs. \(p\) y eligen el número óptimo de regresores según uno de estos criterios:

  1. El valor mínimo de \(\text{MSRes}(p)\)

  2. El valor de \(p\) tal que \(\text{MSRes}(p)\) sea aproximadamente igual al del modelo completo

  3. El valor de \(p\) cercano al punto donde \(\text{MSRes}(p)\) comienza a incrementarse

Este criterio es equivalente al de maximizar \(R^2_{\text{Adj}, p}\). Para verlo, observemos:

\[ R^2_{\text{Adj}, p} = 1 - \left(\frac{n - 1}{n - p}\right)(1 - R^2_p) = 1 - \frac{(n - 1)\text{SSRes}(p)}{(n - p)\text{SST}} = 1 - \frac{\text{MSRes}(p)}{\text{SST}/(n - 1)} \]

Por lo tanto, minimizar \(\text{MSRes}(p)\) es equivalente a maximizar \(R^2_{\text{Adj}, p}\).

8.1.4.2. Estadístico \(C_p\) de Mallows#

Mallows propuso un criterio relacionado con el error cuadrático medio de la predicción:

\[ \text{MSE}(\hat{y}_i) = \left[E(y_i) - E(\hat{y}_i)\right]^2 + \text{Var}(\hat{y}_i) \tag{10.12}\label{eq:10.12} \]

El primer término es el cuadrado del sesgo, y el segundo es la varianza. Definamos la suma de sesgos al cuadrado:

\[ \text{SSB}(p) = \sum_{i=1}^n \left[ E(y_i) - E(\hat{y}_i) \right]^2 \]

y la media cuadrática total estandarizada como:

\[ \Gamma_p = \frac{1}{\sigma^2} \left[ \text{SSB}(p) + \sum_{i=1}^n \text{Var}(\hat{y}_i) \right] \tag{10.13}\label{eq:10.13} \]

Dado que:

\[ \sum_{i=1}^n \text{Var}(\hat{y}_i) = p \sigma^2 \quad \text{y} \quad E[\text{SSRes}(p)] = \text{SSB}(p) + (n - p)\sigma^2 \]

Entonces:

\[ \Gamma_p = \frac{E[\text{SSRes}(p)] - (n - p)\sigma^2 + p\sigma^2}{\sigma^2} = \frac{E[\text{SSRes}(p)]}{\sigma^2} - n + 2p \tag{10.14}\label{eq:10.14} \]

Suponiendo que \(\hat{\sigma}^2\) es una buena estimación de \(\sigma^2\), sustituimos la esperanza por su valor observado:

\[ C_p = \frac{\text{SSRes}(p)}{\hat{\sigma}^2} - n + 2p \tag{10.15}\label{eq:10.15} \]

Si el modelo de \(p\) términos no presenta sesgo, entonces \(\text{SSB}(p) = 0\), y:

\[ E[\text{SSRes}(p)] = (n - p)\sigma^2 \quad \Rightarrow \quad E[C_p] = p \]

Al graficar \(C_p\) contra \(p\), los modelos con poco sesgo se alinean cerca de la línea \(C_p = p\) (punto A). Modelos con alto sesgo estarán por encima (punto B). En general, se prefieren modelos con valores pequeños de \(C_p\). Incluso si un modelo tiene algo de sesgo (por estar por debajo de la línea \(C_p = p\)), puede representar menor error total de predicción (punto C).

Para calcular \(C_p\), se requiere una estimación no sesgada de \(\sigma^2\). Frecuentemente se usa \(\text{MSRes}(K+1)\) del modelo completo. Sin embargo, si el modelo completo contiene regresores no significativos, \(\text{MSRes}(K+1)\) puede sobreestimar \(\sigma^2\), resultando en valores pequeños de \(C_p\).

Como alternativa, puede estimarse \(\sigma^2\) usando pares de observaciones cercanas en el espacio de los regresores.

8.1.5. Criterios de Información: AIC y BIC#

8.1.5.1. Criterio de Información de Akaike (AIC)#

Akaike propuso un criterio de información (AIC) basado en la maximización de la entropía esperada del modelo. La entropía, en este contexto, se refiere a la medida de información de Kullback-Leibler. El AIC es esencialmente una medida del logaritmo de verosimilitud penalizado:

\[ \text{AIC} = -2 \ln(L) + 2p \]

donde \(L\) es la función de verosimilitud del modelo y \(p\) es el número de parámetros. En regresión por mínimos cuadrados ordinarios:

\[ \text{AIC} = n \ln\left( \frac{\text{SSRes}}{n} \right) + 2p \]

Este criterio, al igual que \(R^2_{\text{Adj}}\) y \(C_p\), evalúa si la disminución en \(\text{SSRes}\) justifica el incremento en complejidad del modelo al añadir más regresores.

8.1.5.2. Criterio de Información Bayesiano (BIC)#

Existen varias extensiones bayesianas del AIC, conocidas como criterios BIC. Las más comunes son:

  • Criterio de Schwartz (BIC\textsubscript{Sch}):

\[ \text{BIC}_{\text{Sch}} = -2 \ln(L) + p \ln(n) \]

Para regresión por mínimos cuadrados ordinarios:

\[ \text{BIC}_{\text{Sch}} = n \ln\left( \frac{\text{SSRes}}{n} \right) + p \ln(n) \]

Este criterio penaliza más fuertemente la inclusión de regresores a medida que \(n\) crece.

  • Criterio de Sawa (BIC\textsubscript{Sawa}):
    Es una alternativa empleada en SAS, con una penalización más compleja que involucra \(\sigma^2\) y \(\sigma^4\).

Nota importante: en software como R y SAS, ambos criterios pueden denominarse «BIC», por lo que se debe revisar cuidadosamente cuál versión está implementada.

Estos criterios se emplean con frecuencia en modelos más complejos que la regresión OLS, como los modelos lineales generalizados (ver Capítulo 13) o modelos mixtos (ver Sección 5.6).

8.1.6. Uso de la Regresión y Criterios de Evaluación#

El criterio de evaluación debe relacionarse con el propósito del modelo. Algunos usos comunes de la regresión incluyen:

  1. Descripción de datos:
    Si se desea representar un proceso o sistema complejo, se prefieren modelos con suma de cuadrados residual pequeña. Aunque \(\text{SSRes}\) se minimiza con todos los regresores, conviene eliminar aquellos cuya exclusión no aumente significativamente \(\text{SSRes}\).

  2. Predicción y estimación:
    El objetivo es minimizar el error cuadrático medio de predicción. Esto usualmente implica eliminar regresores con efectos pequeños. Se puede utilizar el estadístico PRESS como criterio:

\[ \text{PRESS}_p = \sum_{i=1}^{n} \left[ y_i - \hat{y}_{(i)} \right]^2 = \sum_{i=1}^{n} \left( \frac{e_i}{1 - h_{ii}} \right)^2 \tag{10.16}\label{eq:10.16} \]

Aunque es útil para evaluar la capacidad predictiva, su cálculo no es trivial ni directamente relacionado con \(\text{SSRes}\).

  1. Estimación de parámetros:
    Se debe considerar tanto el sesgo por exclusión de variables como las varianzas de los coeficientes. En presencia de multicolinealidad, las estimaciones por mínimos cuadrados pueden ser muy inestables (ver Capítulo 9).

  2. Control:
    Cuando se usa el modelo para control, se requieren estimaciones precisas de los coeficientes. Esto implica errores estándar pequeños. Además, como los ajustes sobre \(x\) se basan en los \(\hat{\beta}\), estos deben reflejar fielmente los efectos reales. La multicolinealidad puede comprometer esta fidelidad.

8.2. Técnicas Computacionales para Selección de Variables#

8.2.1. Regresiones de Todos los Posibles Subconjuntos#

Una estrategia directa en Python consiste en ajustar todas las combinaciones posibles de los regresores candidatos, desde modelos con un solo regresor hasta el modelo completo.

Si se tienen \(K\) variables explicativas y se incluye el intercepto, existen \(2^K\) subconjuntos posibles. Por ejemplo:

  • Si \(K = 4\), hay \(2^4 = 16\) modelos

  • Si \(K = 10\), hay \(2^{10} = 1024\) modelos

El número de combinaciones crece exponencialmente con \(K\), por lo cual esta técnica es factible solo para \(K\) pequeños o moderados. Sin embargo, en Python podemos implementarla eficientemente con herramientas como itertools, statsmodels y pandas.

A continuación, se muestra un ejemplo para ajustar todos los modelos posibles y calcular \(R^2_{\text{Adj}}\), AIC y BIC:

import itertools
import pandas as pd
import statsmodels.api as sm

def all_subsets_regression(X, y):
    results = []
    k = X.shape[1]
    for p in range(1, k + 1):
        for subset in itertools.combinations(X.columns, p):
            X_subset = sm.add_constant(X[list(subset)])  # añade intercepto
            model = sm.OLS(y, X_subset).fit()
            results.append({
                "variables": subset,
                "adj_r2": model.rsquared_adj,
                "aic": model.aic,
                "bic": model.bic
            })
    return pd.DataFrame(results).sort_values("adj_r2", ascending=False)

Este procedimiento permite:

  • Explorar todos los modelos posibles con uno o más regresores

  • Comparar modelos con base en \(R^2_{\text{Adj}}\), AIC y BIC

  • Elegir el modelo más parsimonioso que maximice la calidad del ajuste

Nota

La técnica de todas las regresiones posibles en Python es especialmente útil para conjuntos de datos con menos de 15 variables explicativas. Para dimensiones mayores, es preferible usar métodos secuenciales como selección hacia adelante o regresión penalizada (LASSO, Ridge).

Un gráfico de \(R_p^2\) contra \(p\) (ver Figura 10.4) revela que tras incluir dos regresores, las mejoras en \(R^2\) son marginales. 8.3.5. Conclusión#

Este ejemplo ha ilustrado el procedimiento computacional para la selección de modelos usando todas las regresiones posibles. No existe una única elección óptima: distintos criterios conducen a diferentes modelos candidatos.

  • Mínimo \(C_p\): \((x_1, x_2)\)

  • Mínimo \(MSRes\): \((x_1, x_2, x_4)\)

Todos los modelos finales deben evaluarse mediante pruebas estándar: puntos de influencia, apalancamiento y multicolinealidad.

La Tabla 10.4 compara los modelos \((x_1, x_2)\) y \((x_1, x_2, x_4)\) respecto a sus estadísticas PRESS y factores de inflación de la varianza.

Ambos presentan valores similares de PRESS, aproximadamente el doble del \(SSRes\) del modelo con menor \(MSRes\). Además, el \(R^2\) predictivo es comparable. Sin embargo, la alta colinealidad entre \(x_2\) y \(x_4\) en el modelo \((x_1, x_2, x_4)\) se refleja en sus elevados VIFs.

Por tanto, se recomienda el modelo \((x_1, x_2)\) por su menor multicolinealidad.

8.4. Generación eficiente de todas las regresiones posibles#

Existen diversos algoritmos eficientes para generar todas las regresiones posibles. Véanse, por ejemplo, Furnival [1971], Furnival y Wilson [1974], Gartside [1965, 1971], Morgan y Tatar [1972], y Schatzoff, Tsao y Fienberg [1968].

La idea central de estos algoritmos es estructurar los cálculos de los \(2^K\) modelos posibles de forma que modelos sucesivos difieran en una sola variable. Esto permite aplicar métodos numéricos altamente eficientes, usualmente basados en reducción de Gauss–Jordan o en el operador sweep (véase Beaton [1964] o Seber [1977]).

Algunos de estos algoritmos están disponibles comercialmente. Por ejemplo, el algoritmo de Furnival y Wilson [1974] ha sido implementado en software como Python mediante librerías como statsmodels y sklearn.

Una salida típica en Python para los datos de cemento de Hald incluiría los mejores modelos de cada tamaño \(1 \leq p \leq K+1\) según criterios como:

  • \(C_p\)

  • \(R_p^2\)

  • \(MSRes(p)\)

  • \(R_{p,\text{adj}}^2\)

  • \(S = \sqrt{MSRes(p)}\)

Algunos programas también permiten identificar los \(m\) mejores modelos (por ejemplo, \(m \leq 5\)) por cada tamaño \(p\).

Los procedimientos actuales de regresión con todos los subconjuntos pueden manejar eficientemente hasta aproximadamente 30 regresores candidatos, con tiempos de cómputo similares a los métodos stepwise descritos en la Sección 10.2.2.

En nuestra experiencia, problemas con 30 o menos variables suelen resolverse con relativa facilidad mediante este enfoque.

8.5. Métodos de regresión paso a paso#

Dado que evaluar todas las regresiones posibles puede ser computacionalmente costoso, se han desarrollado métodos que consideran solo un subconjunto de modelos al añadir o eliminar una variable por vez. Estos métodos se conocen como procedimientos stepwise, y se clasifican en tres categorías:

  • Selección progresiva (forward selection)

  • Eliminación regresiva (backward elimination)

  • Regresión paso a paso combinada (stepwise regression)

8.5.1. Selección progresiva#

Este procedimiento inicia sin regresores (solo el intercepto) y agrega uno por uno los que más contribuyen. El primer regresor incluido es el que tiene mayor correlación simple con la variable respuesta \(y\), es decir, el que produce el mayor valor \(F\) para evaluar significancia.

Se incluye si el estadístico \(F\) excede un umbral predefinido \(F_{\text{IN}}\) (también llamado F-to-enter). El siguiente candidato es el que presenta la mayor correlación parcial con \(y\), una vez ajustado por el regresor ya incluido.

Sea \(x_1\) el primer regresor. Luego se calculan las correlaciones parciales entre los residuos de:

  • \(\hat{y} = \hat{\beta}_0 + \hat{\beta}_1 x_1\)

  • \(\hat{x}_j = \hat{\alpha}_{0j} + \hat{\alpha}_{1j} x_1\), para \(j = 2, 3, ..., K\)

Supongamos que \(x_2\) es el que tiene la mayor correlación parcial. Entonces se evalúa:

(8.3)#\[ F = \frac{SSR(x_2 \mid x_1)}{MSRes(x_1, x_2)} \]

Si este valor excede \(F_{\text{IN}}\), se incluye \(x_2\). El procedimiento continúa iterativamente, añadiendo el siguiente regresor más relevante si supera el umbral. El algoritmo termina cuando ningún nuevo regresor supera el \(F_{\text{IN}}\) o si ya se han incluido todos los candidatos.

Algunos paquetes computacionales reportan valores-\(t\) en lugar de \(F\) para ingresar o eliminar variables. Esta variante es válida, ya que \(t^2_{\alpha/2, \nu} = F_{\alpha, 1, \nu}\).

La implementación puede realizarse en Python con la función stepwise_selection (ver ejemplos en la librería mlxtend o implementaciones personalizadas con statsmodels).
