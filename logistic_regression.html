10. Regresión Logística#

10.1. Modelos con una Variable de Respuesta Binaria#

  • Consideremos un escenario en el cual la variable de respuesta dentro de un problema de regresión toma únicamente dos valores posibles: \(0\) y \(1\). Esta codificación puede ser una asignación arbitraria derivada de una respuesta cualitativa observada.

  • Por ejemplo, la respuesta puede representar el resultado de una prueba funcional eléctrica en un dispositivo semiconductor, donde los resultados posibles son «éxito» (el dispositivo opera correctamente) o «falla» (debido a un cortocircuito, circuito abierto, u otro defecto funcional).

  • Supongamos que el modelo es de la forma:

    (10.1)#\[ y_i = \mathbf{x}_i' \boldsymbol{\beta} + \varepsilon_i \]

    donde \(\mathbf{x}_{i}^{'} = [1, x_{i1}, x_{i2}, \dots, x_{ik}]\), \(\boldsymbol{\beta} = [\beta_0, \beta_1, \dots, \beta_k]\), y la variable de respuesta \(y_i\) solo puede tomar los valores \(0\) o \(1\).

  • Decimos que, \(\mathbf{x}_i'\boldsymbol{\beta}\) es la parte determinista o sistemática del modelo y \(\varepsilon_i\) es la parte aleatoria, representa el error o la variabilidad no explicada por los predictores.

Distribución de Bernoulli

  • Distribución de Bernoulli: Modelo probabilístico que describe experimentos con únicamente dos resultados posibles:

    • Éxito (\(X = 1\)) con probabilidad \(p\)

    • Fracaso (\(X = 0\)) con probabilidad \(1-p\)

  • Función de Densidad de Probabilidad (FDP)

\[\begin{split} \mathbb{P}(X = x) = \begin{cases} p & \text{si } x = 1 \\ 1-p & \text{si } x = 0 \end{cases} \end{split}\]

Alternativamente:

\[ \mathbb{P}(X = x) = p^x (1-p)^{1-x} \quad \text{para } x \in \{0,1\} \]

  • Propiedades Clave

Concepto

Fórmula

Media (\(\mu\))

\(\mathbb{E}[X] = p\)

Varianza (\(\sigma^2\))

\(\mathbb{Var}(X) = \mathbb{P}(1-p)\)

Ejemplo: Se lanza un dado una vez. Si sale 3, se gana el juego. Si sale cualquier otro número, se pierde. Sea \(X\) la variable aleatoria que representa el número de veces que sale un 3 (éxito).

  • Paso 1: Definir la Variable Aleatoria Bernoulli

    • Espacio muestral: \(\{1, 2, 3, 4, 5, 6\}\) (resultados posibles del dado).

    • Éxito (\(X = 1\)): Sale un 3.

    • Fracaso (\(X = 0\)): Sale cualquier otro número (1, 2, 4, 5, 6).

  • Paso 2: Calcular Probabilidades

    • Probabilidad de éxito (\(p\)):

      \[ \mathbb{P}(X = 1) = \mathbb{P}(\text{Sacar 3}) = \frac{1}{6} \]

    • Probabilidad de fracaso (\(1 - p\)):

      \[ \mathbb{P}(X = 0) = \mathbb{P}(\text{No sacar 3}) = \frac{5}{6} \]

    13.2.2 Estimación de los parámetros en un modelo de regresión logística

  • La forma general del modelo de regresión logística es:

(10.2)#\[ y_i = \mathbb{E}(y_i) + \varepsilon_i \]

donde las observaciones \(y_i\) son variables aleatorias de Bernoulli independientes con valores esperados:

(10.3)#\[ \mathbb{E}(y_i) = \pi_i = \frac{\exp(\mathbf{x}_i' \boldsymbol{\beta})}{1 + \exp(\mathbf{x}_i' \boldsymbol{\beta})} \]

  • Para estimar los parámetros en el predictor lineal \(\mathbf{x}_i' \boldsymbol{\beta}\) se utiliza el método de máxima verosimilitud.

  • Dado que cada observación de la muestra sigue una distribución Bernoulli, la función de probabilidad de cada observación es:

(10.4)#\[ f_i(y_i) = \pi_i^{y_i}(1-\pi_i)^{1-y_i}, \quad i = 1,2,\ldots,n \]

y naturalmente cada \(y_i\) solo puede tomar los valores 0 o 1.

  • Como las observaciones son independientes, la función de verosimilitud es:

(10.5)#\[ L(y_1, y_2, \ldots, y_n, \boldsymbol{\beta}) = \prod_{i=1}^n f_i(y_i) = \prod_{i=1}^n \pi_i^{y_i}(1-\pi_i)^{1-y_i} \]
  $$
  \sigma^2 = \mathbb{Var}(X) = \mathbb{P}(1 - p) = \frac{1}{6} \cdot \frac{5}{6} = \frac{5}{36}
  $$

  • La variable \(X\) sigue una distribución Bernoulli con parámetro \(p = \frac{1}{6}\). Su función de masa de probabilidad (PMF) es:

\[\begin{split} \mathbb{P}(X = x) = \begin{cases} \frac{1}{6} & \text{si } x = 1, \\ \frac{5}{6} & \text{si } x = 0. \end{cases} \end{split}\]

  • Se asume que \(y_i\) es una variable aleatoria Bernoulli, cuya distribución de probabilidad es la siguiente:

\[\begin{split} \begin{align} \mathbb{P}(y_i = 1) &= \pi_i\\ \mathbb{P}(y_i = 0) &= 1 - \pi_i \end{align} \end{split}\]

  • Dado que \(\mathbb{E}(\varepsilon_i) = 0\), el valor esperado de la variable de respuesta es:

\[ \mathbb{E}(y_i) = 1 \cdot \pi_i + 0 \cdot (1 - \pi_i) = \pi_i \]

  • Esto implica:

\[ \mathbb{E}(y_i) = \mathbf{x}_i' \boldsymbol{\beta} = \pi_i \]

  • Es decir, el valor esperado de la variable de respuesta, dado por \(\mathbb{E}(y_i)\), representa directamente la probabilidad de que dicha variable adopte el valor 1.

  • Sin embargo, existen problemas fundamentales con el modelo de regresión en la Ecuación (10.1). En primer lugar, dado que la respuesta es binaria, los términos de error \(\varepsilon_i\) solo pueden tomar dos valores, a saber:

\[\begin{split} \varepsilon_i = \begin{cases} 1 - \mathbf{x}_i' \boldsymbol{\beta}, & \text{si } y_i = 1 \\ - \mathbf{x}_i' \boldsymbol{\beta}, & \text{si } y_i = 0 \end{cases} \end{split}\]

  • En consecuencia, los errores en este modelo no pueden tener distribución normal. En segundo lugar, la varianza del error no es constante, ya que \(\varepsilon_i = y_i - \pi_i=y_{i}-\mathbb{E}(y_i)\) y \(\mathbb{E}(\varepsilon_i) = 0\):

(10.6)#\[ \sigma^2_{y_i} = \mathbb{E} \left\{ (y_i - \mathbb{E}(y_i))^2 \right\} = (1 - \pi_i)^2 \pi_i + (0 - \pi_i)^2 (1 - \pi_i) = \pi_i(1 - \pi_i) \]

  • Obsérvese que esta última expresión puede reescribirse como:

    \[ \sigma^2_{y_i} = \mathbb{E}(y_i)\left[1 - \mathbb{E}(y_i)\right] \]

    Esto implica que la varianza de las observaciones (la cual coincide con la varianza de los errores, pues \(\varepsilon_i = y_i - \pi_i\) y \(\pi_i\) es constante) es función de la media.

  • Finalmente, existe una restricción sobre la función de respuesta, ya que:

\[ 0 \leq \mathbb{E}(y_i) = \pi_i \leq 1 \]

  • Esta restricción puede generar dificultades importantes si se emplea una función de respuesta lineal, como se ha supuesto inicialmente en la ecuación:

(10.7)#\[ y_i = \mathbf{x}_i'\boldsymbol{\beta} + \varepsilon_i \]

  • Podría ajustarse un modelo a los datos tal que los valores predichos de la variable respuesta se encuentren fuera del intervalo \([0, 1]\).

  • Para abordar este problema, se recurre a la transformación de la probabilidad \(\pi_i\) mediante la función logit. El objetivo es transformar \(\pi_i\) en una variable que se encuentre definida en todo el eje real \(\mathbb{R}\)

    \[ \text{logit}(\pi_i) = \log\left(\frac{\pi_i}{1 - \pi_i} \right) \]

    • Esta transformación se llama logit, y se define solo para \(\pi_{i} \in (0,1)\).

    • El cociente \(\dfrac{\pi_{i}}{1 - \pi_{i}}\) se conoce como la razón de probabilidades (odds).

    • La función logit mapea el intervalo \((0,1)\) a todo \(\mathbb{R}\).

  • Ahora sí, podemos aplicar un modelo lineal sobre la transformación logit:

    \[ \log\left(\frac{\pi_i}{1 - \pi_i} \right) = \mathbf{x}_i' \boldsymbol{\beta} \]

    • Esto implica que la razón de odds crece (o decrece) exponencialmente en función lineal de \(\mathbf{x}_{i}\).

    • Se conoce como el modelo lineal en los logits.

  • Queremos recuperar \(\pi_{i}\) en función de \(\mathbf{x}_{i}^\top \boldsymbol{\beta}\). Invirtiendo logit:

    \[\begin{split} \begin{align*} \log\left(\frac{\pi_i}{1 - \pi_i} \right) &= \mathbf{x}_i' \boldsymbol{\beta} \\[8pt] \frac{\pi_i}{1 - \pi_i} &= \exp\left( \mathbf{x}_i' \boldsymbol{\beta} \right) \\[8pt] \pi_i &= \left(1 - \pi_i\right)\exp\left( \mathbf{x}_i' \boldsymbol{\beta} \right) \\[8pt] \pi_i + \pi_i \exp\left( \mathbf{x}_i' \boldsymbol{\beta} \right) &= \exp\left( \mathbf{x}_i' \boldsymbol{\beta} \right) \\[8pt] \pi_i \left( 1 + \exp\left( \mathbf{x}_i' \boldsymbol{\beta} \right) \right) &= \exp\left( \mathbf{x}_i' \boldsymbol{\beta} \right) \\[8pt] \pi_i &= \frac{\exp\left( \mathbf{x}_i' \boldsymbol{\beta} \right)}{1 + \exp\left( \mathbf{x}_i' \boldsymbol{\beta} \right)} \\[8pt] &= \frac{1}{1 + \exp\left( -\mathbf{x}_i' \boldsymbol{\beta} \right)} \end{align*} \end{split}\]

  • Esta es la función logística o sigmoide:

    \[ \mathbb{E}(y_i) = \pi_i = \frac{1}{1 + \exp(-\mathbf{x}_i' \boldsymbol{\beta})} \]

    • Mapea cualquier valor real a una probabilidad entre 0 y 1.

    • Se utiliza para clasificar casos entre dos clases: \(y_{i} = 1\) o \(y_{i} = 0\).

  • Nótese que, un incremento en una variable explicativa \(\mathbf{x}_i\) incrementa o disminuye log-odds de que \(y_{i} = 1\). Además, el parámetro \(\beta_j\) mide el cambio en el logit por unidad adicional en \(\mathbf{x}_i\), manteniendo fijos los demás predictores.

10.2. Estimación de los parámetros en un modelo de regresión logística#

  • La forma general del modelo de regresión logística es:

    (10.8)#\[ y_i = \mathbb{E}(y_i) + \varepsilon_i \]

    donde las observaciones \(y_i\) son variables aleatorias de Bernoulli independientes con valores esperados:

    (10.9)#\[ \mathbb{E}(y_i) = \pi_i = \frac{\exp(\mathbf{x}_i' \boldsymbol{\beta})}{1 + \exp(\mathbf{x}_i' \boldsymbol{\beta})} \]

  • Para estimar los parámetros en el predictor lineal \(\mathbf{x}_i' \boldsymbol{\beta}\) se utiliza el método de máxima verosimilitud. Dado que cada observación de la muestra sigue una distribución Bernoulli, la función de probabilidad de cada observación es:

    (10.10)#\[ f_i(y_i) = \pi_i^{y_i}(1-\pi_i)^{1-y_i}, \quad i = 1,2,\ldots,n \]

    y naturalmente cada \(y_i\) solo puede tomar los valores 0 o 1.

  • Como las observaciones son independientes, la función de verosimilitud es:

(10.11)#\[ L(y_1, y_2, \ldots, y_n, \beta) = \prod_{i=1}^n f_i(y_i) = \prod_{i=1}^n \pi_i^{y_i}(1-\pi_i)^{1-y_i} \]

  • Es más conveniente trabajar con la log-verosimilitud:

(10.12)#\[ \ln L(y_1, y_2, \ldots, y_n, \boldsymbol{\beta}) = \ln \prod_{i=1}^n f_i(y_i) = \sum_{i=1}^n \left[ y_i \ln \left(\frac{\pi_i}{1-\pi_i}\right)\right] + \sum_{i=1}^n \ln(1-\pi_i) \]

  • Como \(1 - \pi_i = [1 + \exp(\mathbf{x}_i' \boldsymbol{\beta})]^{-1}\) y al definir \(\eta_i = \ln\!\left(\pi_i/(1-\pi_i)\right) = \mathbf{x}_i' \boldsymbol{\beta}\), la log-verosimilitud puede reescribirse como:

(10.13)#\[ \ln L(\boldsymbol{y}, \boldsymbol{\beta}) = \sum_{i=1}^n y_i \mathbf{x}_i' \boldsymbol{\beta} - \sum_{i=1}^n \ln \big[ 1 + \exp(\mathbf{x}_i' \boldsymbol{\beta}) \big] \]

  • En modelos de regresión logística es común tener observaciones o ensayos repetidos en cada nivel de las variables \(x\). Esto ocurre con frecuencia en experimentos diseñados.

  • Sea \(y_i\) el número de éxitos observados en la \(i\)-ésima unidad y \(n_i\) el número de ensayos correspondientes, esto es, \(Y_i \sim \text{Bernoulli}(n_{i}, \pi_i)\)) y la probabilidad de observar \(y_i\) éxitos es

\[ f_i(y_i) = \binom{n_i}{y_i}\pi_i^{y_i}(1-\pi_i)^{n_i-y_i} \]

  • Por lo tanto, la verosimilitud total es

\[ L(y_1, y_2, \ldots, y_n, \boldsymbol{\beta}) = \prod_{i=1}^n \binom{n_i}{y_i}\pi_i^{y_i}(1-\pi_i)^{n_i-y_i} \]

  • Tomando logaritmo

\[ \ln L(\boldsymbol{y}, \boldsymbol{\beta}) = \sum_{i=1}^n \Bigg[ \ln \binom{n_i}{y_i} + y_i \ln(\pi_i) + (n_i-y_i)\ln(1-\pi_i) \Bigg] \]

  • El término

    \[ \ln \binom{n_i}{y_i} = \ln \frac{n_i!}{y_i!(n_i-y_i)!} \]

    no depende de \(\pi_i\) ni de los parámetros \(\boldsymbol{\beta}\). Es decir, es una constante respecto a la estimación de máxima verosimilitud. Como en máxima verosimilitud lo que importa es maximizar la función respecto a \(\boldsymbol{\beta}\), se pueden eliminar los términos constantes, ya que no afectan la localización del máximo. Entonces

    (10.14)#\[ \ln L(\boldsymbol{y}, \boldsymbol{\beta}) = \sum_{i=1}^n y_i \ln(\pi_i) + \sum_{i=1}^n (n_i - y_i)\ln(1-\pi_i) \]

  • Calculemo estimadores de máxima verosimilitud (MLEs) \(\hat{\boldsymbol{\beta}}\) mediante el procedimiento de Iteratively Reweighted Least Squares (IRLS). Al derivar con respecto a \(\pi_i\), se obtiene:

(10.15)#\[ \frac{\partial \ln L(\boldsymbol{y}, \boldsymbol{\beta})}{\partial \pi_i} = \frac{y_i}{\pi_i} - \frac{n_i-y_i}{1-\pi_i} = \frac{y_i}{\pi_i} - \frac{n_i}{1-\pi_i} + \frac{y_i}{1-\pi_i} \]

  • Ahora, para propagar la derivada hacia \(\boldsymbol{\beta}\), usamos que \(\pi_i = \exp(\mathbf{x}_i'\boldsymbol{\beta})/(1+\exp(\mathbf{x}_i'\boldsymbol{\beta}))\). Calculemos \(\partial\pi_i/\partial\boldsymbol{\beta}\). Sea \(z_i = \mathbf{x}_i'\boldsymbol{\beta}\) entonces \(\pi_i = \exp(\mathbf{x}_i'\boldsymbol{\beta})/(1+\exp(\mathbf{x}_i'\boldsymbol{\beta}))\)

(10.16)#\[ \frac{d\pi_i}{dz_i} = \frac{\exp(z_i)\big(1+\exp(z_i)\big) - \exp(z_i)\exp(z_i)}{\big(1+\exp(z_i)\big)^2} = \frac{\exp(z_i)}{\big(1+\exp(z_i)\big)^2}. \]

  • Reescribiendo esta última expresión en términos de \(\pi_i\) y \((1-\pi_i)\)

(10.17)#\[ \frac{\exp(z_i)}{(1+\exp(z_i))^2} = \underbrace{\frac{\exp(z_i)}{1+\exp(z_i)}}_{\displaystyle{\pi_i}}\; \underbrace{\frac{1}{1+\exp(z_i)}}_{\displaystyle{1-\pi_i}} = \pi_i(1-\pi_i). \]

  • Gradiente de \(z_i\) respecto a \(\boldsymbol{\beta}\) (forma vectorial) \(\partial z_i/\partial\boldsymbol{\beta}=\mathbf{x}_i'\). Aplicando la regla de la cadena

(10.18)#\[ \frac{\partial \pi_i}{\partial \boldsymbol{\beta}} = \frac{d\pi_i}{dz_i}\,\frac{\partial z_i}{\partial \boldsymbol{\beta}} = \pi_i(1-\pi_i)\,\mathbf{x}_i' = \frac{\exp(\mathbf{x}_i'\boldsymbol{\beta})}{\big(1+\exp(\mathbf{x}_i'\boldsymbol{\beta})\big)^2}\,\mathbf{x}_i'. \]

  • Aplicando la regla de la cadena:

(10.19)#\[ \frac{\partial \ln L(\boldsymbol{y}, \boldsymbol{\beta})}{\partial \boldsymbol{\beta}} = \sum_{i=1}^n \left[ \frac{\partial \ln L}{\partial \pi_i} \cdot \frac{\partial \pi_i}{\partial \boldsymbol{\beta}} \right] \]

  • Sustituyendo (10.15) y (10.18) en (10.19):

(10.20)#\[ \frac{\partial \ln L(\boldsymbol{y}, \boldsymbol{\beta})}{\partial \boldsymbol{\beta}} = \sum_{i=1}^n \left[\frac{y_i}{\pi_i} - \frac{n_i}{1-\pi_i} + \frac{y_i}{1-\pi_i}\right] \pi_i (1-\pi_i)\mathbf{x}_i' \]

  • Para simplificar la expresión, partimos de la forma expandida del gradiente de la log-verosimilitud:

\[\begin{split} \begin{align*} \frac{\partial \ln L(\boldsymbol{y}, \boldsymbol{\beta})}{\partial \boldsymbol{\beta}} &= \sum_{i=1}^n \left[\frac{y_i}{\pi_i} - \frac{n_i}{1-\pi_i} + \frac{y_i}{1-\pi_i}\right] \pi_i (1-\pi_i)\,\mathbf{x}_i'\\[6pt] &= \sum_{i=1}^n \left[\frac{y_i}{\pi_i} + \frac{y_i-n_i}{1-\pi_i}\right] \pi_i (1-\pi_i)\,\mathbf{x}_i' \quad\text{(agrupar términos semejantes)}\\[6pt] &= \sum_{i=1}^n \left[\frac{y_i}{\pi_i}\pi_i(1-\pi_i) + \frac{y_i-n_i}{1-\pi_i}\pi_i(1-\pi_i)\right]\mathbf{x}_i' \quad\text{(distribuir)}\\[6pt] &= \sum_{i=1}^n \left[y_i(1-\pi_i) + (y_i-n_i)\pi_i\right]\mathbf{x}_i' \quad\text{(cancelar $\pi_i$ y $1-\pi_i$)}\\[6pt] &= \sum_{i=1}^n \left[y_i - y_i\pi_i + y_i\pi_i - n_i\pi_i\right]\mathbf{x}_i' \quad\text{(desarrollar)}\\[6pt] &= \sum_{i=1}^n (y_i - n_i\pi_i)\,\mathbf{x}_i' \end{align*} \end{split}\]

  • Por lo tanto, el estimador de máxima verosimilitud \(\hat{\boldsymbol{\beta}}\) se obtiene resolviendo la ecuación de score

    (10.21)#\[ \mathbf{X}'(\boldsymbol{y} - \boldsymbol{\mu}) = 0 \]

    donde \(\boldsymbol{\mu} = (n_1\pi_1, \ldots, n_n\pi_n)'\) es el vector de medias esperadas bajo el modelo logístico.

  • Este conjunto de ecuaciones suele denominarse ecuaciones de score de máxima verosimilitud. En realidad, adoptan la misma forma que las ecuaciones normales vistas previamente en el método de mínimos cuadrados lineales.

  • En el modelo de regresión lineal se cumple que \(\mathbb{E}(\boldsymbol{y}) = \mathbf{X}\boldsymbol{\beta} = \boldsymbol{\mu}\), y las ecuaciones normales son:

(10.22)#\[ \mathbf{X}'\mathbf{X}\hat{\boldsymbol{\beta}} = \mathbf{X}'\boldsymbol{y} \]

  • Que puede reescribirse como:

\[\begin{split} \begin{align} \mathbf{X}'(\boldsymbol{y} - \mathbf{X}\boldsymbol{\beta}) &= 0\\ \mathbf{X}'(\boldsymbol{y} - \boldsymbol{\mu}) &= 0 \end{align} \end{split}\]

  • En el caso de la regresión logística, las ecuaciones de score se resuelven mediante el método de Newton-Raphson. Se busca aproximar cómo varía \(\pi_i\) cuando \(\boldsymbol{\beta}\) se ajusta hacia \(\boldsymbol{\beta}^*\) (el estimador que satisface las ecuaciones de verosimilitud).

  • Se emplea una expansión de Taylor de primer orden para \(\pi_i(\boldsymbol{\beta})\) alrededor de \(\boldsymbol{\beta}\):

    \[\pi_i(\boldsymbol{\beta}^*) \approx \pi_i(\boldsymbol{\beta}) + \left( \frac{\partial \pi_i}{\partial \boldsymbol{\beta}} \right)' (\boldsymbol{\beta}^* - \boldsymbol{\beta})\]

  • Dado que el valor óptimo \(\boldsymbol{\beta}^*\) satisface \(p_i \approx \pi_i(\boldsymbol{\beta}^*)\) en las ecuaciones de score, donde \(p_i = y_i/n_i\) y \(\boldsymbol{\beta}^*\), es el valor de los coeficientes \(\boldsymbol{\beta}\) que maximiza la función de verosimilitud, es decir, el conjunto de valores que hace que las probabilidades predichas por el modelo \(\pi_{i}:=\pi_{i}(\boldsymbol{\beta})\) sean lo más parecidas posible a las proporciones observadas \(p_{i}\)

    \[p_i \approx \pi_i(\boldsymbol{\beta}) + \left( \frac{\partial \pi_i}{\partial \boldsymbol{\beta}} \right)' (\boldsymbol{\beta}^* - \boldsymbol{\beta})\]

  • Reordenando términos

    (10.23)#\[p_i - \pi_i \approx \left( \frac{\partial \pi_i}{\partial \boldsymbol{\beta}} \right)' (\boldsymbol{\beta}^* - \boldsymbol{\beta})\]

  • Si definimos \(\eta_i = \mathbf{x}_i'\boldsymbol{\beta}\), se cumple que \(\partial \eta_i/\partial\boldsymbol{\beta} = \mathbf{x}_i\). Además, recordemos que \(\pi_i = \exp(\eta_i)/(1+\exp(\eta_i))\)

  • Aplicando la regla de la cadena:

(10.24)#\[ \frac{\partial \pi_i}{\partial \boldsymbol{\beta}} = \frac{\partial \pi_i}{\partial \eta_i} \cdot \frac{\partial \eta_i}{\partial \boldsymbol{\beta}} = \frac{\partial \pi_i}{\partial \eta_i}\mathbf{x}_i \]

  • Por lo tanto, podemos reescribir la aproximación en Ecuación (10.23) como

    \[\begin{split} \begin{align*} p_i - \pi_i &\approx \left(\frac{\partial \pi_i}{\partial \eta_i}\right)\mathbf{x}_i'(\boldsymbol{\beta}^* - \boldsymbol{\beta}) \\ &= \left(\frac{\partial \pi_i}{\partial \eta_i}\right)(\mathbf{x}_i'\boldsymbol{\beta}^* - \mathbf{x}_i'\boldsymbol{\beta}) \\ &= \left(\frac{\partial \pi_i}{\partial \eta_i}\right)(\eta_i^* - \eta_i) \end{align*} \end{split}\]

    donde \(\eta_{i}^{*}\) es el valor de \(\eta_{i}\) evaluado en \(\boldsymbol{\beta}^{*}\).

  • Se observa que

    \[(y_{i}-n_{i}\pi_{i})=(n_{i}p_{i}-n_{i}\pi_{i})=n_{i}(p_{i}-\pi_{i})\]

    y dado que \(\pi_{i}=\exp(\eta_{i})/(1+\exp(\eta_{i}))\) y además

\[\frac{\partial\pi_i}{\partial\eta_i} = \pi_i (1 - \pi_i)\]

  • Entonces, combinando las expresiones anteriores

\[p_i - \pi_i \approx \left(\frac{\partial \pi_i}{\partial \eta_i}\right)(\eta_i^* - \eta_i) = \pi_i (1 - \pi_i) (\eta_i^* - \eta_i)\]

  • Lultiplicando ambos miembros por \(n_i\) (tamaño muestral)

\[n_i(p_i - \pi_i) \approx n_i \pi_i (1 - \pi_i) (\eta_i^* - \eta_i)\]

  • Dado que, el lado izquierdo equivale a \(y_i - n_i \pi_i\), se deduce

(10.25)#\[ y_i - n_i \pi_i \approx n_i \pi_i (1 - \pi_i) (\eta_i^* - \eta_i) \]

  • A continuación, se calcula la varianza para ambos miembros de la aproximación precedente. El miembro izquierdo es directo: la varianza de \((y_i - n_i \pi_i)\) es simplemente la varianza de \(y_i\), que para una distribución Binomial resulta

\[\text{Var}(y_i - n_i \pi_i) = \text{Var}(y_i) = n_i \pi_i (1 - \pi_i)\]

  • El miembro derecho requiere el método delta. La regla fundamental establece: para una constante \(c\) y una variable aleatoria \(X\), \(\text{Var}(cX) = c^2 \text{Var}(X)\). En nuestra aproximación, el término \(n_i \pi_i (1 - \pi_i)\) se considera una constante conocida (o evaluada en la estimación corriente), no como una variable aleatoria. De este modo

\[\begin{split} \begin{align} \text{Var}(y_i - n_i \pi_i) &\approx \text{Var}\left( [n_i \pi_i (1 - \pi_i)] (\eta_i^* - \eta_i) \right) \\ n_i \pi_i (1 - \pi_i) &\approx \left[ n_i \pi_i (1 - \pi_i) \right]^2 \cdot \text{Var}(\eta_i^* - \eta_i) \end{align} \end{split}\]

  • Ahora es posible resolver la ecuación para hallar la varianza de interés, \(\text{Var}(\eta_i^*)\). Nótese que \(\eta_i\) es un valor fijo (el valor «verdadero»), por lo cual \(\text{Var}(\eta_i^* - \eta_i) = \text{Var}(\eta_i^*)\)

\[n_i \pi_i (1 - \pi_i) \approx \left[ n_i \pi_i (1 - \pi_i) \right]^2 \cdot \text{Var}(\eta_i^*)\]

  • Para despejar \(\text{Var}(\eta_i^*)\), dividimos ambos lados entre \(\left[ n_i \pi_i (1 - \pi_i) \right]^2\)

\[\frac{n_i \pi_i (1 - \pi_i)}{\left[ n_i \pi_i (1 - \pi_i) \right]^2} \approx \text{Var}(\eta_i^*)\]

  • Simplificando la fracción:

(10.26)#\[ \text{Var}(\eta_i^*)\approx\frac{1}{n_i \pi_i (1 - \pi_i)} \]

  • Por lo tanto, usando las Ecuaciones (10.25) y (10.26) se tiene que

\[y_{i}-n_{i}\pi_{i}\approx\left[\frac{1}{\mathrm{Var}\big{(}\eta_{i}^{*}\big{)}}\right ](\eta_{i}^{*}-\eta_{i})\]

  • Usando la Ecuación (10.21), se pueden reescribir las ecuaciones de verosimilitud como

\[\sum_{i=1}^{n}\left[\frac{1}{\mathrm{Var}(\eta_{i})}\right](\eta_{i}^{*}-\eta_{ i})\mathbf{x}_i'=0\Leftrightarrow\mathbf{X}^{\prime}\mathbf{V}^{-1}(\boldsymbol{\eta}^{*}-\boldsymbol{\eta})=\mathbf{0}\]

  • Siendo \(\mathbf{V}\) una matriz diagonal con los pesos formados a partir de las varianzas de los \(\eta_{i}\). Debido a que \(\boldsymbol{\eta}=\mathbf{X}\boldsymbol{\beta}\) es posible escribir las ecuaciones de score como

\[\mathbf{X}^{\prime}\mathbf{V}^{-1}(\boldsymbol{\eta}^{*}-\mathbf{X}\boldsymbol{\beta})=\mathbf{0}\]

  • Aplicando álgebra matricial, se obtiene el estimador de máxima verosimilitud para \(\boldsymbol{\beta}\)

(10.27)#\[\begin{split} \begin{align} \mathbf{X}'\mathbf{V}^{-1}\eta^* - \mathbf{X}'\mathbf{V}^{-1}\mathbf{X}\boldsymbol{\beta} &= 0 \\[6pt] \mathbf{X}'\mathbf{V}^{-1}\mathbf{X}\boldsymbol{\beta} &= \mathbf{X}'\mathbf{V}^{-1}\eta^* \\[6pt] \hat{\boldsymbol{\beta}} &= (\mathbf{X}'\mathbf{V}^{-1}\mathbf{X})^{-1}\mathbf{X}'\mathbf{V}^{-1}\eta^* \end{align} \end{split}\]

  • Sin embargo, existe una dificultad porque se desconoce \(\eta^{*}\). Para solucionar esto, partimos de la expansión de Taylor de primer orden

    (10.28)#\[\begin{split} \begin{align} p_i - \pi_i &= \left(\frac{\partial\pi_i}{\partial\eta_i}\right)(\eta_i^* - \eta_i) && \text{(expansión de Taylor)} \\[6pt] \eta_i^* &= \eta_i + (p_i - \pi_i)\frac{\partial\eta_i}{\partial\pi_i} && \text{(regla de la función inversa)} \\[6pt] z_i &= \eta_i + (p_i - \pi_i)\frac{\partial\eta_i}{\partial\pi_i} && \text{(definición de variable pseudo-respuesta)} \end{align} \end{split}\]

    donde \(z_i\) se conoce como la variable pseudo-respuesta (working variable).

  • El paso de actualización para \(\beta\) se obtiene resolviendo un problema de mínimos cuadrados ponderados en cada iteración

    (10.29)#\[ \begin{align} \hat{\boldsymbol{\beta}} = (\mathbf{X}'\mathbf{V}^{-1}\mathbf{X})^{-1}\mathbf{X}'\mathbf{V}^{-1}\mathbf{z} && \text{(estimador IRLS)} \end{align} \]

    con \(\mathbf{z} = (z_1,\dots,z_n)'\) y \(\mathbf{V} = \mathrm{diag}\!\left[1/(n_i\pi_i(1-\pi_i))\right]\).

  • Algoritmo IRLS

  1. Inicializar \(\hat{\boldsymbol{\beta}}_0\) (por OLS). Se parte de una estimación preliminar lineal.

  2. Calcular probabilidades y pesos: \(\hat{\pi}_i = g^{-1}(\mathbf{x}_i'\hat{\boldsymbol{\beta}}_k)\), \(\hat{\mathbf{V}} = \mathrm{diag}\!\left[1/(n_i\hat{\pi}_i(1-\hat{\pi}_i))\right]\). Los pesos provienen de la varianza binomial.

  3. Construir pseudo-respuesta: \(\mathbf{z} = (z_1,\dots,z_n)'\), linealización local del predictor con corrección de residuales.

  4. Actualizar estimador

    \[ \hat{\boldsymbol{\beta}}_{k+1} = (\mathbf{X}'\hat{\mathbf{V}}^{-1}\mathbf{X})^{-1}\mathbf{X}'\hat{\mathbf{V}}^{-1}\mathbf{z} \]

    Estimador por mínimos cuadrados ponderados.

  5. Iterar hasta convergencia: \(\|\hat{\boldsymbol{\beta}}_{k+1} - \hat{\boldsymbol{\beta}}_k\| < \epsilon\). El proceso converge al estimador máximo verosímil.

  • Análisis de la Varianza. La componente aleatoria de \(z_{i}\) es

\[(p_{i}-\pi_{i})\frac{\partial\eta_{i}}{\partial\pi_{i}}\]

  • Por lo tanto, por propiedades de la varianza

\[\begin{split} \begin{align*} \text{Var}\!\left[(p_i - \pi_i)\frac{\partial \eta_i}{\partial \pi_i}\right] &= \left(\frac{\partial \eta_i}{\partial \pi_i}\right)^2 \text{Var}(p_i - \pi_i) \\[6pt] &= \left(\frac{\partial \eta_i}{\partial \pi_i}\right)^2 \text{Var}(p_i) \end{align*} \end{split}\]

  • Dado que

\[\begin{split} \begin{align*} p_i &= \frac{y_i}{n_i}, \quad y_i \sim \text{Binomial}(n_i, \pi_i) \\[6pt] \text{Var}(p_i) &= \frac{1}{n_i^2}\text{Var}(y_i) \\[6pt] &= \frac{1}{n_i^2} \, n_i \pi_i (1-\pi_i) \\[6pt] &= \frac{\pi_i (1-\pi_i)}{n_i} \end{align*} \end{split}\]

  • Sustituyendo en la fórmula de varianza

\[ \begin{align*} \text{Var}\!\left[(p_i - \pi_i)\frac{\partial \eta_i}{\partial \pi_i}\right] &= \left(\frac{\partial \eta_i}{\partial \pi_i}\right)^2 \cdot \frac{\pi_i (1-\pi_i)}{n_i} \end{align*} \]

  • Dado que, para el caso logit

\[\begin{split} \begin{align*} \eta_i &= \log\!\left(\frac{\pi_i}{1-\pi_i}\right) \\[6pt] \frac{\partial \eta_i}{\partial \pi_i} &= \frac{1}{\pi_i} + \frac{1}{1-\pi_i} \\[6pt] &= \frac{1}{\pi_i (1-\pi_i)} \end{align*} \end{split}\]

  • Sustituyendo se tiene que

\[\begin{split} \begin{align*} \text{Var}\!\left[(p_i - \pi_i)\frac{\partial \eta_i}{\partial \pi_i}\right] &= \left(\frac{1}{\pi_i(1-\pi_i)}\right)^2 \cdot \frac{\pi_i(1-\pi_i)}{n_i} \\[6pt] &= \frac{1}{n_i \pi_i (1-\pi_i)} \end{align*} \end{split}\]

  • Así, \(\mathbf{V}\) es la matriz diagonal de pesos construida a partir de las varianzas de la parte aleatoria de \(z\).

  • Implementación en Python

import numpy as np
from scipy.linalg import inv

def newton_raphson_irls(X, p, n, max_iter=25, tol=1e-6):
    """
    Implementación del algoritmo IRLS usando el método de Newton-Raphson
    para regresión logística
    """
    # Paso 1: Estimación inicial por MCO
    beta_hat = inv(X.T @ X) @ X.T @ np.log(p / (1 - p))
    
    for iteration in range(max_iter):
        # Paso 2: Estimar pi y V
        eta = X @ beta_hat
        pi = 1 / (1 + np.exp(-eta))
        V = n * pi * (1 - pi)
        V_inv = np.diag(1 / V)
        
        # Paso 3: Calcular variable ajustada z
        d_eta_d_pi = 1 / (pi * (1 - pi))
        z = eta + (p - pi) * d_eta_d_pi
        
        # Paso 4: Actualizar estimación de beta
        Xt_V_inv = X.T @ V_inv
        beta_new = inv(Xt_V_inv @ X) @ Xt_V_inv @ z
        
        # Verificar convergencia
        if np.linalg.norm(beta_new - beta_hat) < tol:
            break
            
        beta_hat = beta_new
    
    return beta_hat

  • Existen varias bibliotecas en Python que implementan estimación por máxima verosimilitud para regresión logística, como statsmodels o scikit-learn.

  • Sea \(\hat{\boldsymbol{\beta}}\) el estimador final de los parámetros del modelo obtenido por el algoritmo. Si se cumplen los supuestos, asintóticamente se tiene que:

(10.30)#\[ \mathbb{E}(\hat{\boldsymbol{\beta}}) = \boldsymbol{\beta}, \quad \text{Var}(\hat{\boldsymbol{\beta}}) = (X' V X)^{-1} \]

donde \(V\) es una matriz diagonal \(n \times n\) que contiene en la diagonal la varianza estimada de cada observación, es decir, el elemento \(i\) de la diagonal es:

(10.31)#\[ V_{ii} = n_i \hat{\pi}_i (1-\hat{\pi}_i) \]

  • El valor estimado del predictor lineal es \(\hat{\eta}_i = \mathbf{x}_i' \hat{\boldsymbol{\beta}}\) y el valor ajustado del modelo logístico es:

(10.32)#\[ \hat{y}_i = \hat{\pi}_i = \frac{\exp(\hat{\eta}_i)}{1+\exp(\hat{\eta}_i)} = \frac{\exp(\mathbf{x}_i' \hat{\boldsymbol{\beta}})}{1+\exp(\mathbf{x}_i' \hat{\boldsymbol{\beta}})} = \frac{1}{1+\exp(-\mathbf{x}_i' \hat{\boldsymbol{\beta}})} \]
